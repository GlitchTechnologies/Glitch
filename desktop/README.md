# Glitch для Windows

Программа для компьютера — это веб-версия Glitch (web.glitchapp.online) в своём окне, как у Discord. Сам Glitch — тот же, что на сайте: исправления интерфейса появляются в программе сразу после обновления сайта, без переустановки. Программа добавляет только то, чего браузер не умеет: окно со своей полосой сверху, заставку при запуске, значок в трее с меню (открыть, микрофон, звук, выйти — обычное меню Windows), одну копию, окно выбора экрана для показа, «Сохранить как», уведомления Windows о сообщениях и звонках, красную точку, когда есть что прочитать, открытие наших ссылок (`glitch://` — кнопка «Открыть в Glitch» на странице ссылки `glitchtech.ru`), запуск вместе с Windows (сразу в трей) и выбор, что делает ✕ — раздел «Система» в настройках Glitch, самообновление при запуске.


## Что где

| Папка / файл | Что это |
|---|---|
| `src/main/` | сама программа: окно, заставка, трей, связь с Glitch (каждый файл подписан в начале) |
| `src/preload/` | что страница Glitch получает от программы (`window.glitchDesktop`) |
| `src/main/hotkeys.ts` | горячие клавиши самой программы (перезагрузка, масштаб): умолчания, выбранные человеком в разделе «Горячие клавиши» Glitch (хранятся в программе), правило «какие нажатия ловит» |
| `src/main/global-keys.ts` | горячие клавиши Glitch поверх других окон (рация в игре): запускает `glitch-keys.exe`, пока Glitch просит, и передаёт ему, какие клавиши слушать |
| `keys/` | `glitch-keys.exe` (C#, .NET Framework 4.8, как окно установщика) — слышит клавиатуру и мышь поверх других окон штатным способом Windows (Raw Input, не перехват) и сообщает только попрошенные клавиши; собирается шагом `npm run keys` (входит в `npm run dist`), кладётся в `resources` программы |
| `src/main/games.ts` | «Играет в»: запускает `glitch-games.exe`, пока Glitch просит, сверяет запущенные программы со справочником игр (его присылает Glitch) и отдаёт Glitch только найденные игры |
| `games/` | `glitch-games.exe` (C#, .NET Framework 4.8, как `glitch-keys.exe`) — по просьбе перечисляет запущенные процессы: путь к файлу и время запуска (у Electron этого нет); собирается шагом `npm run games` (входит в `npm run dist`), кладётся в `resources` программы |
| `src/main/popouts.ts` | отдельные окна Glitch («Отладка» голоса) — единственное место, где они заводятся |
| `src/shared/ipc.ts` | единственный список каналов связи «Glitch ↔ программа» |
| `update-window/` + `src/main/update-window.ts` | `glitch-update.exe` (C#, .NET Framework 4.8) — окно «Установка обновления…» на месте заставки, пока ставится новая версия (с 2026-11-07, как у Discord; раньше экран ~15 с был пуст). Только показывается: ставит обновление по-прежнему `updater.ts`. Программа запускает его копию из временной папки, оно уходит само, когда новая версия показала заставку (или через 3 минуты). Вид повторяет `static/splash.html` — поменяли заставку, поменять `update-window/UpdateWindow.cs` |
| `src/main/log.ts` | журнал программы (с 2026-11-07, как у Discord): события окна, трея, запуска и выхода, плюс `console.warn/error` главного процесса — в `%APPDATA%\Glitch\logs\desktop.log` (перерос 1 МБ — `desktop.old.log`). Пишет только он (`logEvent`), без адресов и ссылок целиком. Разбор «что-то не так у человека» — сначала этот файл |
| `static/` | заставка, логотип, значки: `icon.ico`, `icon-unread.ico` (с красной точкой у часов; значок с числом на панели задач рисуется на ходу — `src/preload/app-preload.ts`) |
| `installer/` | окно установщика (маленькое тёмное окно с выбором папки); `engine.nsh` — добавка к движку установки: удаление программы снимает схему `glitch://` и автозапуск |
| `scripts/` | шаги сборки установщика (`prepare-setup.js` — движок и размер для окна установщика, `check-style.js` — сверка цветов и мягкой кнопки программы и установщика с приложением); `make_icons.py` — значки из `mobile/assets/icon.png` (того же значка, что у Glitch на телефоне): поменялся логотип — `python3 desktop/scripts/make_icons.py` и положить три файла `static/` вместе |

Со стороны Glitch связь с программой — `mobile/lib/services/desktop_shell*.dart`, «мы в программе?» — `isDesktopApp` в `mobile/lib/core/platform_info.dart`.

## Подготовка ПК (один раз)

1. **Node.js** — https://nodejs.org, версия с пометкой LTS. Установить с галочками по умолчанию.
2. **.NET SDK** — https://dotnet.microsoft.com/download, раздел «.NET SDK» (любая версия от 8). Нужен для окна установщика, для `glitch-keys.exe` (клавиши поверх других окон), `glitch-games.exe` (запущенные игры) и для `glitch-update.exe` (окно «Установка обновления…»).
3. **Rust x64 MSVC** — [rustup.rs](https://rustup.rs/) и Visual Studio
   Build Tools с нагрузкой «Разработка классических приложений на C++»
   и Windows SDK. Нужны на ПК сборки нативного захвата.
4. Открыть терминал в папке `desktop` и выполнить:

   ```
   npm install
   ```

   Скачает Electron и сборщик (около 300 МБ). Повторять — только если поменялся `package.json`.

## Собрать установщик


То же вручную, в папке `desktop`:

```
npm install
npm run dist
```

Готовый установщик находится в `dist\GlitchSetup.exe`.

Если сборка остановилась с ошибкой про «symbolic link» / «A required privilege is not held by the client» — включить в Windows «Режим разработчика» (Параметры → Конфиденциальность и защита → Для разработчиков) или запустить терминал от имени администратора и повторить.

### Демонстрация через DXGI и WASAPI

Установи обычный `dist\GlitchSetup.exe`. Glitch загружает актуальную
веб-версию, поэтому ей нужна поддержка нативного захвата.
При одном подключённом мониторе Glitch пробует DXGI для пункта
«Экраны», если кадр помещается в выбранное разрешение. Для проверки
выбери разрешение «Источник». Опция «Поделиться звуком» запускает WASAPI.

В «Отладка → Видео → Захват экрана» ожидаются `DXGI · BGRA · видеокарта`
и `WASAPI`. Для отдельного окна, нескольких активных мониторов или
раннего отказа DXGI Glitch использует штатный захват Chromium. Если при
активном DXGI аварийно закрылась страница или вся программа, в этой версии
Glitch продолжит использовать штатный захват. Этап запуска и причина
перехода видны в `%APPDATA%\Glitch\logs\desktop.log`.

При входе в полноэкранную игру Windows может закрыть интерфейс DXGI.
Glitch до трёх секунд восстанавливает захват того же монитора, сохраняя
видеодорожку и WASAPI. Успех виден в журнале по строке «DXGI восстановил
захват того же монитора». При отключении монитора или отсутствии
восстановления показ завершается.

## Запустить без установки (проверка)

```
npm start
```

Программа откроется сразу, без установщика. С инструментами разработчика — `npx electron . --glitch-devtools` (после `npm run build`).

## Версия программы

Версия программы задаётся полем `version` в `package.json`. По этому полю программа определяет, доступно ли обновление.
